### 6. Risks and overflow guards

| Risk | Mitigation |
|---|---|
| Template exercises already in day (dedup) | `loadTemplateRows` de-dupes by exerciseId before replacing â€” keeps first row by orderIndex |
| BB3 clear path: wrong week/day index | Read current controller `activeBlockId`, `blockStartDate`, `selectedDate` to derive `week_{N}/day_{N}` before clearing â€” same logic as existing BB3 write-back paths |
| Undo after template load restoring wrong `wasLoadedFromTemplate` state | Include both `_rows`, `_wasLoadedFromTemplate`, `_loadedTemplateName` in the undo frame |
| `wesPlannedExercises[]` array grow unbounded on repeated template loads | `_repository` save for template load must **set** (replace) the array, not append â€” use the same merge/set logic used for manual add |
| Template picker exercise-name overflow | Every exercise chip/row text wrapped in `Flexible` + `maxLines: 1` + `TextOverflow.ellipsis` |
| "Save to templates" label overflow in bottom row | Wrap in `Flexible`; never bare `Text` in unconstrained `Row` |
| Network failure on `saveWorkoutAsTemplate` | Catch and show snackbar error; do not queue offline (internet required) |
